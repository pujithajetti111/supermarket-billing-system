# Supermarket Billing System 🛒

A beginner-friendly **Python-based Supermarket Billing System** that allows users to select products, add quantities to a cart, and generate a final bill.

## Features

* Display available supermarket items and prices
* Select multiple products
* Add quantities to the shopping cart
* Automatically calculate item-wise amounts
* Generate the final bill
* Calculate the total purchase amount
* Handle unavailable products and invalid quantities

## Technologies Used

* Python
* Dictionaries
* Lists
* Loops
* Conditional Statements
* User Input

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run:

```bash
python supermarket_billing.py
```

5. Enter the item names and quantities.
6. Type `done` when you have finished shopping.

## Example

```text
===== SUPERMARKET BILLING SYSTEM =====

Available Items:
rice ₹ 60
sugar ₹ 45
oil ₹ 120
milk ₹ 30

Enter item name (or 'done' to finish): rice
Enter quantity: 2

rice added to cart.

Enter item name (or 'done' to finish): milk
Enter quantity: 3

milk added to cart.

Enter item name (or 'done' to finish): done

========== FINAL BILL ==========
Item        Qty     Price   Amount
Rice        2       ₹60     ₹120
Milk        3       ₹30     ₹90
--------------------------------
Total Amount: ₹ 210
```
